SHADOWLINE — a top-down stealth game: slip past patrolling guards and their vision cones, hide behind crates and in bushes, grab the intel, and reach the green EXIT unseen across 3 hand-built levels. A live detection meter shows when you are WATCHED, SUSPECTED, or in full ALARM; click the floor to throw a noisemaker and lure a guard away. Keyboard + mouse, no network, runs from static files.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
